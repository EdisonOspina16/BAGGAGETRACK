# BaggageTrack - Shell de examen

Proyecto base para el Examen Practico 2 de Desarrollo de Aplicaciones Moviles.

## Estado inicial

La aplicacion contiene:

- Catalogo local de equipajes.
- Modelo `Baggage`.
- Modelo base `BaggageEvent`.
- Pantalla principal.
- Pantalla de detalle.
- Navegacion entre listado y detalle.
- Archivos base para database, servicio remoto y repository.

La shell **no incluye** Firebase, Cloud Firestore ni Drift como dependencias.
La implementacion de esas tecnologias forma parte del examen.

## Antes de comenzar

Ejecute:

```bash
flutter pub get
flutter run
```

La aplicacion inicial debe abrir y permitir navegar entre el listado de equipajes y el detalle.

Consulte el enunciado oficial para los requerimientos del examen y la variante asignada.
